# Project Store with ERP integration.

This project was built for learning purposes. There are two parts, a store and the ERP.
The two parts are integrated with each other, to simulate a buying process with cart validations, queues, security validadions etc, like SAP Commerce with Spring Boot structure.

## Prerequisites:
- Java 21;
- Docker

## Run Commerce-service:
make sure you are in the commerce-service folder then type:
  ```bash
  cd commerce-service
  ./mvnw spring-boot:run
  ```
