#Project Store with ERP integration.

This Project was built to purpose of learning. There are two parts, a store and the ERP.
Both with integrations with one and others, to simulate a buying process with cart validations, queues, security validadions etc, like SAP Commerce with Spring Boot structure.

Prerequisites:
- Java 21;
- Docker

Run Commerce-service:
make sure you are in commerce-service folder then type:
./mvnw spring-boot:run
